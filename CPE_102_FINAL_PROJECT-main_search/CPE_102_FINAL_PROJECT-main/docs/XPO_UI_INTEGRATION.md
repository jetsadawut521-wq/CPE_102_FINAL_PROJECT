# บันทึกการผสานแนวทาง UI ของ Xpo

branch นี้นำแนวทางภาพจาก [ไฟล์ออกแบบ Xpo ใน Figma](https://www.figma.com/design/Qt1lA1U6By5tHL3Fa5lstW/Xpo?node-id=62-3289&t=IYTaqi3BBZjpDMX4-1) มาปรับใช้กับแอป Muverse เดิม ไฟล์ Figma เป็นข้อมูลอ้างอิงด้านการออกแบบ ส่วน repository นี้มีแอปที่ทำงานได้และ logic ของฟีเจอร์

## ส่วนที่นำแนวทางมาใช้

- อัตลักษณ์ MUVERSE และแถบนำทางหลักสำหรับค้นหา ฝึกเต้น และเพลย์ลิสต์
- ส่วนแนะนำบนหน้าแรก ช่องค้นหาที่เห็นชัด ตัวอักษรหัวเรื่อง และสีเขียวไลม์
- ลำดับพื้นผิวสำหรับวิดีโอที่กำลังดู รายการส่วนตัว ประวัติการดู และผลค้นหา
- การจัดวางที่ปรับตามจอ โดยวาง player และแผนผังฟอร์เมชันซ้อนกันในจอแคบ
- รูปแบบร่วมสำหรับสถานะ Random Dance การจัดการเพลย์ลิสต์ การแก้ไฮไลท์ การตั้งค่าพื้นเวที และหน้าต่างเลือกเพลย์ลิสต์
- หน้าจอเต็มที่แสดงเครื่องมือฝึกและไฮไลท์ไว้ในแผงด้านข้าง พร้อมปุ่มเปิด/ปิดแผง

คอมโพเนนต์ React และสถานะแอปยังดูแลการเล่น YouTube การวิเคราะห์และแก้ไฮไลท์ การวิเคราะห์/ปรับเทียบ/แก้ฟอร์เมชัน ชื่อนักเต้น เพลย์ลิสต์ และ Random Dance การปรับภาพถูกผสานเข้ากับ flow เหล่านี้

## ขอบเขตของการผสาน

- ไฟล์ Figma มีหน้าจอและ flow มากกว่าที่แอปทำงานได้ branch นี้จัดรูปแบบ flow ที่มีอยู่ ไม่สร้างปุ่มที่ยังไม่มีพฤติกรรมรองรับ
- เพลย์ลิสต์ ผลวิเคราะห์ calibration ชื่อนักเต้น และประวัติการดูเก็บใน `localStorage` ของเบราว์เซอร์ ยังไม่มีระบบบัญชีหรือซิงก์ข้ามอุปกรณ์
- การค้นหาและเล่นวิดีโอยังขึ้นกับการตั้งค่า YouTube API และความพร้อมของ YouTube embed ส่วนการวิเคราะห์ฟอร์เมชันใหม่ต้องเปิด worker ในเครื่อง ผลที่บันทึกไว้แล้วเปิดดูได้โดยไม่ต้องวิเคราะห์ซ้ำ
- หน้าจอเป็นการนำทิศทางและระบบภาพบางส่วนมาใช้ ไม่ใช่การ export ทุก frame จาก Figma แบบ pixel-perfect

## แหล่งที่มา

ใช้ไฟล์ Figma เป็นเพียงข้อมูลอ้างอิง ไม่มีการนำ source code หรือ asset จาก Figma มาวางในแอป Flow ตั้งค่าพื้นเวทีอ้างอิงแนวคิดจาก [GridStage](https://github.com/ChangShengHsun/GridStage) โดยอธิบายการพัฒนาแยกและ license ไว้ใน [README](../README.md)

## เปิดใช้งานในเครื่อง

```powershell
npm ci
npm run build
npm run dev
```

เว็บเปิดที่ `http://localhost:3100` หากต้องการวิเคราะห์ฟอร์เมชัน ให้เปิด Python worker ตาม [คู่มือติดตั้งและส่งต่องาน](DEVELOPER_GUIDE.md) การ build ตรวจการคอมไพล์ของเว็บ ส่วนการเล่น YouTube และ worker ต้องอาศัยการตั้งค่าและบริการที่พร้อมใช้งาน
